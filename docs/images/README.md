# Images for documentation

Add figures here for the main [`README.md`](../../README.md).

**Logo:** [`logo.svg`](logo.svg) is used at the top of the root README. Replace that file (or point the README at your own `logo.png` / `logo.svg`) if you want a different brand mark.

**Suggested asset for the repo landing page:** `coverage.png` — e.g. satellite or map overview with the driven / mapped area highlighted. In `README.md`, reference it as:

```markdown
![Coverage area — Berlin, Str. des 17. Juni](docs/images/coverage.png)
```
